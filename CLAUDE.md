# Правила коммитов

- Коммиты делать от имени пользователя (git author/committer — данные из `git config user.name`/`user.email`, они уже настроены на аккаунт владельца репозитория).
- Не добавлять в сообщение коммита `Co-Authored-By: Claude ...` и `Claude-Session: ...` — никаких ссылок на Claude или сессию.
