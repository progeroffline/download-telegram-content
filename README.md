# download-telegram-content

Скачивает медиа (фото, видео, документы, альбомы) из сообщений Telegram по ссылке на сообщение.

## Установка

```bash
uv sync
cp .env.example .env
```

Получи `TELEGRAM_API_ID` и `TELEGRAM_API_HASH` на https://my.telegram.org/apps и впиши их в `.env`.

## Запуск

```bash
uv run main.py
```

При первом запуске Telethon попросит номер телефона и код подтверждения — так создаётся локальная сессия (`*.session`), дальше логиниться не нужно.

Дальше просто вставляй ссылку на сообщение:

```
> https://t.me/some_channel/123
Скачано: downloads/some_channel_123.jpg
```

Поддерживаются:
- публичные каналы: `https://t.me/username/123`
- приватные каналы: `https://t.me/c/1234567890/123` (нужно быть участником канала)
- альбомы (несколько фото/видео в одном сообщении) — скачаются все файлы группы

Файлы сохраняются в `downloads/`. Прогресс скачивания каждого файла показывается прогресс-баром (rich), логи — через loguru.

## Все видео канала

Чтобы скачать все видео из канала, передай его username или ссылку:

```bash
uv run main.py --channel some_channel
uv run main.py --channel https://t.me/some_channel
```

Для приватного канала можно использовать ссылку вида `https://t.me/c/1234567890`;
аккаунт из локальной Telegram-сессии должен состоять в этом канале.

Сообщения обрабатываются от самых старых к самым новым. Видео сохраняются с
исходными именами и раскладываются по дате и времени публикации в часовом поясе
Украины (`Europe/Kyiv`):

```text
downloads/2026/09/02/1600/original-video-name.mp4
```

Если у видео в Telegram нет исходного имени, используется резервное имя
`message_<id>.<расширение>`. Уже существующие файлы пропускаются, поэтому
прерванную загрузку можно безопасно запустить повторно.

По умолчанию одновременно скачивается до 4 видео (разные файлы, не части
одного) — это может дать прирост суммарной скорости, если упор не в
одно MTProto-соединение, а в лимит на файл/DC. Число параллельных загрузок
настраивается флагом `--concurrency`:

```bash
uv run main.py --channel some_channel --concurrency 8
```
